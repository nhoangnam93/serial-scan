Camera HTTPS Setup

Complete these steps once per iPhone/iPad.

1. Open scanner with https:// URL (not http).
2. Tap Install Cert and install profile.
3. Go to Settings > General > About > Certificate Trust Settings.
4. Enable trust for NAB Scanner Certificate.
5. Return to scanner page and allow camera access.
